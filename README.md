# 70C 전용 (김포 70C 버스 앱)

김포 **70C번** 한 노선만을 위한 모바일 웹앱(PWA)입니다. 노선도 위에서 70C 버스가 지금 어디쯤
가고 있는지 한눈에 보고, 정류장을 누르면 다음 버스 도착 예정 시간을 확인할 수 있습니다.

- 기점: **힐스테이트리버시티2단지정문** → 회차·종점: **김포공항역 3번출구** (편도 9개 정류장, 왕복 18개 지점)
- 평일 **44회**, 토·일·공휴일 **36회** (기점 출발 기준)

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 뼈대 (상단 상태, 노선도 탭, 시간표 탭, 정류장 바텀시트) |
| `styles.css` | 디자인 (딥 네이비 + 블루/에메랄드, Pretendard 웹폰트, 카드·바텀시트) |

| `sw.js` | 서비스 워커 (앱 화면은 캐시, 데이터는 항상 새로 계산) |

## 동작 방식

### 1) 노선도 — 지금 어디쯤인가

- 왼쪽 파란 선이 **김포공항역 방면(상행)**, 오른쪽 청록색 선이 **힐스테이트2단지 방면(하행)** 입니다.
  아래쪽 둥근 점선 구간이 **김포공항역 회차** 구간입니다.
- 시간표의 기점 출발 시각마다 버스 한 대가 기점을 떠나 김포공항역까지 갔다가(14분) 회차(3분) 후
  다시 기점으로 돌아오는(15분) 것으로 계산해, **한 바퀴 32분** 기준으로 위치를 잡습니다.
- 실시간 정보를 받으면 그 위치(`stationSeq`)에 차량번호가 찍힌 버스가 표시되고, 30초마다 갱신됩니다.
  실시간이 막히면 시간표로 계산한 위치로 자동 전환됩니다.
- 버스 아이콘은 1초에 여러 번 위치를 다시 그려 부드럽게 움직입니다. 실제 속도는 눈에 잘 띄지 않으므로
  노선도 오른쪽 위 `1×` 버튼을 누르면 **30배속 데모**로 바뀌어 움직임을 바로 확인할 수 있습니다
  (데모 중에는 화면에 "실제 시각과 다릅니다"라고 표시됩니다).
- 버스를 누르면 그 버스가 **다음에 도착할 정류장**의 도착 시간 패널이 열립니다.
- 30초마다 자동으로 다시 계산되고, 오른쪽 위 **새로고침** 버튼으로 즉시 갱신할 수 있습니다.

### 2) 정류장 → 도착 시간

정류장(점 또는 이름)을 누르면 아래에서 패널이 올라와 다음을 보여 줍니다.

- 실시간 도착정보가 있으면 `곧 도착 / N분 후 도착`, `N정거장 전`과 함께 LIVE 표시
- 도착 예정 차량이 없으면 시간표로 추정하지 않고 **`도착 예정 차량 없음`**으로 표기합니다
- 정차 / 미정차(통과) 여부 — 고촌IC·개화사거리·김포공항입구는 70C가 지나가기만 하는 구간입니다
- ★ 즐겨찾기 (브라우저에 저장, 노선도 위에 바로가기 칩으로 표시)

### 3) 시간표 — 평일 44회 / 토·일·공휴일 36회

- 오늘 날짜에 맞는 시간표가 기본으로 열리고, 지금 이후 **다음 출발 회차가 하이라이트**됩니다.
- 각 회차 옆에 실제 배차간격(분)이 함께 표시됩니다.

## 데이터 출처

- **시간표**: 사용자가 보낸 김포시 게시 시간표 사진 (2025. 7. 1. 시내버스 정규노선 전환, 차량 7대,
  운행 06:00~22:00, 평시 배차 20~40분) — `app.js`의 `WEEKDAY` / `WEEKEND` 배열
- **노선·정류장**: 경기버스정보 노선 `route_id 232000145` (18개 지점, 정류장 고유번호 포함)
- **구간 소요 시간**: 정류장별 표정속도 추정치 (`STOPS`의 `t` 값) — 실제 도로 상황과 다를 수 있습니다
- **공휴일**: `app.js`의 `HOLIDAYS` 목록. 임시공휴일은 반영되지 않으므로 해마다 갱신이 필요합니다.

## 실시간 연동 (공공데이터포털)

두 가지 API를 함께 씁니다. 둘 다 `apis.data.go.kr`이 `Access-Control-Allow-Origin`을 직접
돌려주어서 **중계 서버 없이 브라우저에서 바로** 호출합니다. (허용 출처: `https://nada797979-prog.github.io`)

| 용도 | API | 주기 |
| --- | --- | --- |
| 노선 전체 버스 위치 | `buslocationservice/v2/getBusLocationListv2?routeId=232000145` | 30초 (화면이 보일 때만) |
| 정류장별 도착 정보 | `busarrivalservice/v2/getBusArrivalItemv2?stationId=…&routeId=232000145` | 정류장을 누를 때 + 30초 |

- 위치 응답의 `stationSeq`(1~18)를 노선 정류장 순서에 그대로 대응시켜, 버스 아이콘에
  차량번호 뒤 4자리(`plateNo`)와 저상버스 배지·혼잡도 색(여유/보통/혼잡/매우혼잡)을 표시합니다.
- 도착 응답의 `locationNo1`(몇 정거장 전)·`predictTime1`(분)·`plateNo1`·`crowded1`·`lowPlate1`로
  `1정거장 전 · 2분 후 도착 (6299호 · 저상 · 여유)`처럼 보여 줍니다.
- 정류장별 GBIS `stationId`는 `STOPS[].sid`에 들어 있습니다(경기버스정보 노선 232000145의 정류장 순서 기준).
- 실패·오프라인·CORS 거부·`file://` 실행 시에는 아무 표시 없이 **시간표 기반 예상 위치**로 돌아갑니다.
- 호출 한도(일 1,000건)를 지키기 위해 **화면이 보일 때만** 30초마다 조회하고, 앱이 백그라운드로
  가면 멈춥니다. 같은 정류장의 도착 정보는 20초 동안 캐시합니다.
- 그날 호출 수를 `localStorage`에 세어 두고, 820건을 넘으면 2분·930건을 넘으면 5분 간격으로
  자동으로 늘려 한도 소진을 막습니다.

## 올리는 방법

- GitHub Pages 예: 저장소 `gimpo-70c`에 이 폴더의 파일을 올리고 Settings → Pages → Branch `main` / root
